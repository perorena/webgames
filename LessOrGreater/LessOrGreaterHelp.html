【不等号パズル】遊び方
空いているマスに数字を入れて、すべての不等号（>・<）を成立させるロジックパズルです。
1. 基本ルール
・1から盤面の1辺のマス数（3×3なら1〜3、4×4なら1〜4）までの数字をプルダウンから選んで入れます。
・次の2つの条件をすべて満たすとクリアです。
① 隣り合うマスの大小が不等号どおりになっていること（口が開いている方が大きい数字）
② 同じ行（横1列）と同じ列（縦1列）に同じ数字が入らないこと
完成イメージ（3×3・1〜3を使う場合）
3 > <
> < >
< 3 >
> > <
< < 3
➡
すべて成立
3 > 1 < 2
> < >
2 < 3 > 1
> > <
1 < 2 < 3
※大小が正しく成立した不等号は水色に変わります。縦と横に同じ数字が重複すると赤いメッセージでお知らせします。
2. いろいろな遊び方・攻略のコツ
・不等号が連続する場所（チェーン）を探す：3×3で「□ < □ < □」のように同じ向きの不等号が並んでいる列は、自動的に「1 < 2 < 3」と数字が確定します。
・最大・最小の数字の居場所を絞る：周囲のすべての不等号から「より小さい」と指されているマスには「1」しか入りません。
・問題番号を変えて挑戦：上のプルダウンから問題を切り替えると、4×4・5×5…と盤面が大きくなり、本格的なロジックパズルが楽しめます。
3. 画面の見方とボタン
・[RESET]ボタンをクリック（タップ）すると最初からやり直す事ができます。
